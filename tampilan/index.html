Deskripsi projek

Sistem ini merupakan prototipe pemantauan lingkungan berbasis Internet of Things (IoT) yang mengintegrasikan mikrokontroler ESP32 (diprogram menggunakan MicroPython) dan sensor DHT22 untuk membaca data suhu serta kelembaban udara secara akurat. Data telemetri dikirimkan secara periodik via protokol HTTP POST menuju backend API, kemudian divisualisasikan secara real-time dan historis pada dashboard ini.
